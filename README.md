# paisano-site

Proyecto base para el portafolio interactivo de paisano.

## Abrir localmente

Puedes abrir el archivo index.html directamente en el navegador o servir la carpeta con un servidor simple.

Ejemplo:

```bash
cd /Users/valeriaelisabetminjolou/Desktop/web/paisano-site
python3 -m http.server 8000
```

Luego abre:

```text
http://127.0.0.1:8000/
```
